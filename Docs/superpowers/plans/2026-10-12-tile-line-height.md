# 桌面便签行距

**Goal:** 在设置中调整所有桌面钉住便签的正文行距，并自动保存和实时同步。

**Architecture:** 沿用 AppConfig 的持久化和 config-changed 广播，在 Tile 内设置 CSS 行距变量。以 Tile 为作用域覆盖纯文本、Markdown 和列表正文的固定行高，并让待办框跟随列表首行居中。

**Tech Stack:** React、TypeScript、CSS、Tauri、Rust。

## 设计

- 设置项放在“小窗/磁贴字号”下方，标签为“桌面便签行距”。
- 使用滑块，范围 1.0～3.0 倍，步长 0.1，默认 1.8 倍。
- 使用全局配置 tileLineHeight；旧配置缺少此字段时采用默认值。
- 配置读写时校正非有限值和超出范围的值。
- 桌面便签即时响应 config-changed；标题保留现有行高。
- 列表复选框、项目符号与第一行文字保持垂直居中。
