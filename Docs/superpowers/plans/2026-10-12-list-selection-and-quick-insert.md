# 列表便签行内时间、全选与快捷插入类型

**Goal:** 时间标签与正文同行，显示 `MM-DD HH:mm`；整份列表可全选；时间记录和剪贴板追加分别允许设置普通/待办节点。

**Architecture:** 时间继续保存完整日期，悬停查看完整值。共享列表编辑器提供列表级选择、剪贴板及替换操作，保留逐行文本框及撤销历史。设置通过现有 Tauri 配置持久化和 config-changed 事件同步，旧配置默认普通节点。

## 实现步骤

- [x] 行内短时间标签，在编辑和钉选预览中保持同行。
- [x] Ctrl+A / Cmd+A 和右键全选整份列表，包括折叠节点；支持复制、剪切、删除、粘贴/输入替换和撤销，钉选预览仍可跨行选择。
- [x] 设置页增加两个独立类型选项；Rust 持久化、兼容旧配置和无效值；打开的便签实时采用设置。
- [x] 回归测试时间、跨条目选择和两种快捷插入；运行全量前端测试、类型检查、lint、生产构建及相关 Rust 测试。
