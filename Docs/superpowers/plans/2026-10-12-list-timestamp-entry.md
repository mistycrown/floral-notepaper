# 列表便签时间记录

**Goal:** 在钉选列表的剪贴板按钮旁加入时间记录按钮，进入编辑模式并追加、聚焦带当前时间的条目。

**Architecture:** 采用用户确认的固定格式 `YYYY-MM-DD HH:mm`，使用本机当前时间。条目以 `[YYYY-MM-DD HH:mm] 正文` 存储，与现有 Markdown 和列表保存方式兼容。共享列表编辑器在编辑和钉选预览时将时间渲染为带时钟图标的小标签，正文独立输入。

**Tech Stack:** React、TypeScript、Tauri、Vitest。
