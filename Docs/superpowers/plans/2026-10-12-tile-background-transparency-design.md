# 钉选便签背景透明度设计

用户确认仅背景透明，标题、正文、Markdown、列表和按钮保持原有清晰度。

- 在设置的磁贴颜色附近增加“钉选便签背景透明度”滑块，0%–80%，步进 1%。默认 0%，保留现有外观。
- 全局字段 `tileBackgroundTransparency` 表示透明百分比，自动保存并通过现有 `config-changed` 事件即时同步所有钉选窗口。主窗口和编辑小窗保持原有背景。
- `Tile` 接收可选 `backgroundTransparency`，只将便签背景颜色的 alpha 调整为 `1 - transparency / 100`，不设置容器 opacity。边框、内容、按钮及 Markdown 派生色保持原值。
- 旧配置缺失字段时取 0；前端防护非有限值，后端读写将超过 80 的数值限制为 80。
- 验证设置交互、初始窗口配置、实时更新、模式切换、独立便签颜色、配置兼容与重启持久化。
